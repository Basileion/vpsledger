Frequently asked questions
What is your billing model?
Cloud products are billed on an hourly basis using a postpaid billing model. This means that usage costs are not charged immediately when a resource is created. Instead, the accumulated usage is recorded and invoiced in the following billing cycle. Even if a Cloud Server or other resources have already been deleted, charges for the time they were active may still remain on the account until the next invoice is generated. As long as there are outstanding charges that have not yet been invoiced, the account cannot be permanently deleted. Account deletion is only possible once all invoices have been issued and fully paid.
Is there any way to get a custom configuration?
Customized virtual servers (additional RAM, additional/larger drives etc.) are not currently available.
What is the bandwidth of your Cloud Servers?
The host systems for our Cloud instances all have a redundant 10 Gbits connection. This connection is shared by all instances on the host. We do not offer bandwidth guarantees for our Cloud servers, but you can expect about 300-500 Mbits.
Is there a library to access Hetzner Cloud from my programming language?
We currently maintain official open source libraries for
Go
and
Python
. You can find libraries for other languages created by the community in our
Awesome Hetzner Cloud List

docs.hetzner.cloud

Do you plan to add x feature?/Will you add more features?
We want to keep adding new features and services and are always interested in hearing from you on how we can improve our product! There are several ways you can provide us with product feedback or feature requests:
Via our forum: please post your request in the
Hetzner Cloud Board
Via email: send us your ideas to
product-feedback@hetzner.com
Unfortunately, we cannot give you a detailed roadmap of what we are working on. However, you can keep up to date by following us on our social media channels.
Can I install Windows?
Right now we are focusing on support for Linux as an operating system. If you wish, you may install Windows on your own, and we have seen successful installations done. However, we will not provide any support for Windows.
What linux distributions do you support?
Hetzner supports a range of common Linux distributions: Ubuntu, Fedora, Debian, CentOS, Rocky Linux and AlmaLinux. You can choose these when creating Cloud Servers or have them preinstalled on Dedicated Servers; you can also install any other OS manually via KVM/ISO.
Does Hetzner have an SLA?
Yes, we have an SLA that guarantees 99.9% uptime. In the event of a clearly defined malfunction, you will receive a credit note. You can find all the important information about this in our
SLA
