# VPSLedger: shared directory listing blurb

**Name:** VPSLedger
**URL:** https://vpsledger.pages.dev

**Tagline (49/60 chars):** The true monthly cost of a VPS, sourced and dated

**Short description (≤160):**
See what a VPS really costs: list price plus IPv4, backups and bandwidth. 33 plans, 15 providers, every price sourced and dated. Free.

**Long description (≤500):**
Sticker prices leave out IPv4, backups and bandwidth overage. VPSLedger adds them back for 33 plans across 15 providers, including Hetzner, OVHcloud, Vultr, DigitalOcean and Linode. It ranks plans for your specs and links every price to the provider's own page, with the date it was checked. For the same 2 vCPU / 4 GB, verified plans range from $4.54 to $29/mo. The calculator, compare pages and JSON data are free. Pro ($9/mo) adds price-drop alerts and CSV export.
