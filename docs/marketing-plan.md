# VPSLedger marketing plan: free channels open to a new account (prep only, nothing posted)

Ready today (no account history needed): **dev.to**, **Hashnode**, **Medium (own profile)**, **GitHub awesome-list PRs**. Not today: **LowEndTalk**.

## 1. dev.to: ready today
- Copy: docs/devto-article.md. It has front matter with `published: false`, so it can be pasted as-is and published manually.
- Rules: new accounts can publish. Use at most 4 tags. Disclose affiliate links (already done in the article).

## 2. Hashnode: ready today
- Free blog on a hashnode.dev subdomain. A new account can publish right away.
- In the article settings, set the **canonical URL** to the dev.to post or to https://vpsledger.pages.dev/ so the copies don't compete for SEO.
- Copy: the same body as docs/devto-article.md, without the front matter. Tags: devops, cloud, self-hosted, web-development.
- Title: "The same 2 vCPU / 4 GB VPS costs $4.54 or $29 a month: I priced 33 plans"

## 3. Medium: ready today on your own profile. Publications come later.
- Post on your own profile using Medium's "Import a story" with the dev.to URL. That sets the canonical link automatically.
- Publications only accept writers they've added, and each has its own submission rules. Read the "Submit" page of DevOps- or cloud-focused publications before pitching. Most want an unpublished draft and no promotional content, so lead with the data, not with Pro.
- Copy: same as dev.to. Subtitle: "IPv4, backups, egress and promo renewals, added back with sources."

## 4. GitHub awesome lists (PRs): ready today
Read each list's CONTRIBUTING file before opening a PR. Use the list's format, one line, neutral wording, and disclose that you're the author.
- **jmfontaine/awesome-finops**: https://github.com/jmfontaine/awesome-finops. The README says "Contributions welcome!" and links CONTRIBUTING.md. Section: Tools → Commercial Tools (it's freemium).
  - Line: `- [VPSLedger](https://vpsledger.pages.dev/) - True monthly VPS cost (list price + IPv4, backups, egress) for 33 plans across 15 providers, with every price sourced and dated. Open JSON data (CC BY 4.0).`
- **ElementTech/awesome-cloud-cost**: https://github.com/elementtech/awesome-cloud-cost (tips for saving on cloud costs). Same line, in its tools/resources section.
- **wearetechnative/awesome-finops**: it has a contributing.md that requires a new branch, an existing section and a standard linked-entry format. Same line.
- PR title: "Add VPSLedger (VPS true-cost comparison)". PR body: "Free calculator and open JSON dataset comparing VPS total cost of ownership. Disclosure: I'm the author."
- Skip **awesome-selfhosted**. It only lists software you can self-host, and VPSLedger is a hosted site.
